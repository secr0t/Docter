# 🩺 Doctor

> **像看医生一样，诱出你自己都没意识到的真实问题。**

Doctor 是一个面向 **问题诊断与根因分析** 的 AI Skill。

它不会在看到一个现象后立即给出结论，而是通过持续追问、建立假设、收集证据和排除其他可能，逐步判断：

**到底出了什么问题，以及为什么会出现这个问题。**

------

## ✨ 核心理念

Doctor 和 Grill-me，就像**看病和治病**。

|            | 🩺 Doctor                                                     | 🔨 Grill-me                                                   |
| ---------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 核心任务   | **把问题问对**                                               | **把问题想透**                                               |
| 像医生一样 | “哪里不舒服？”→“具体哪里？”→“什么时候开始？”→“还有什么症状？”→一步步找到真正的病因 | “既然知道是什么病了，那怎么治？”→“有哪些方案？”→“哪个更好？”→“有没有遗漏？”→不断推演解决方案 |
| 解决的问题 | **我真正出了什么问题？**                                     | **这个问题应该怎么解决？**                                   |
| 最终产物   | 🎯 **真正的问题 / 根因**                                      | 💡 **经过思考的解决方案**                                     |

Doctor 不会因为你说“我头疼”，就直接告诉你吃什么药。

它会像医生问诊一样，**从你描述的表面症状出发，不断追问、缩小范围，直到把你真正的问题找出来。**

而 Grill-me 则是在问题已经明确之后，**逼着你把解决方案想完整、想深入、想透彻。**

> **🩺 Doctor：把问题问对。**
> **🔨 Grill-me：把问题想透。**

------

## 🎯 Doctor 负责什么？

Doctor 只负责一件事情：

> **确定病因。**

它负责：

-  识别用户描述中的真实症状
-  区分事实、推测和结论
-  建立多个可能的问题假设
-  通过高价值问题获取关键信息
-  收集能够证明或否定假设的证据
-  比较不同诊断之间的可能性
-  排除不成立的解释
-  深入分析问题的根因
-  最终形成明确的诊断

Doctor **不负责治疗**。

因此它不会在诊断过程中直接进入：

```text
❌ 修复方案
❌ 代码修改
❌ 实施方案
❌ 技术整改
❌ Remediation Plan
```



------

## 🔨 Doctor × Grill-me

Doctor 完成诊断后，不进入 Solver。

正确关系是：

```text
🩺 Doctor
    │
    │  找到病因
    ▼
Confirmed Diagnosis
    │
    │  接受挑战
    ▼
🔨 Grill-me
    │
    ├── 诊断成立
    │      ↓
    │   Validated Diagnosis
    │
    └── 诊断存在问题
           ↓
        返回 Doctor
```

Grill-me 的任务不是重新替 Doctor 做一遍普通诊断，而是：

- 挑战关键证据
- 寻找反例
- 检查是否存在遗漏
- 尝试推翻当前诊断
- 检查根因是否只是表面现象
